# איזה כלי הייתם בוחרים? · משחק הצבעה

משחק הצבעה חי לסדנת AI בזום: המשתתפים מצביעים מהטלפון איזה כלי AI מתאים לכל תרחיש, והתוצאות מופיעות בזמן אמת במסך המנחה (/host).

**לינק לאתר החי:** https://which-ai-tool.sites.tab.bot/

---
האתר רץ כ-Cloudflare Worker: `_worker.js` הוא צד השרת (שמירת ההצבעות במסד D1, לפי `tab-site.json`), ושאר הקבצים הם צד הלקוח.

### קוד המנחה (מסך /host)
קוד המנחה **לא** שמור בקוד הציבורי. ב-`_worker.js` הקבוע הוא `const HOST_KEY = "CHANGE_ME";`, ובמצב הזה מסך המנחה חסום.
כדי להפעיל עותק משלכם: החליפו את `CHANGE_ME` בקוד אקראי משלכם (או הגדירו משתנה סביבה `HOST_KEY`), ואז מסך המנחה נפתח בכתובת `/host?k=<הקוד>`.
באתר החי מוגדר קוד אחר, שלא מופיע כאן.
